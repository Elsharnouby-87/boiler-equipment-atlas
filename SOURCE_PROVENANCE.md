# Source Provenance

## UI / interaction authority

The visual and interaction foundation is intentionally derived from the existing Process Equipment Atlas repository:

- dark blue/black industrial workspace
- orange active-state accent
- three-column Atlas layout
- Three.js / WebGL interaction pattern
- normal / cutaway / x-ray / exploded study modes
- focus and isolate learning states
- mobile navigation sheets and responsive controls

Reference repository:
https://github.com/Elsharnouby-87/process-equipment-atlas

## Boiler training authority

Primary project content source:

**الغلايات.pdf** — supplied for this project.

Topics used in the current implementation include:

- definition and classification of steam boilers
- fire-tube and water-tube configurations
- boiler body, burner, level sensors, gauge glass, pressure controls and safety valve
- feedwater and non-return valve concepts
- blowdown
- startup, purge, ignition and flame confirmation
- cold-start / warm-up considerations
- water-level and pressure protection
- water treatment, deposits and TDS-related operating concerns
- daily operating checks and troubleshooting concepts

## Training boundary

The Atlas is an educational visualization. It does not replace:

- boiler OEM manuals
- certified drawings
- Burner Management System cause-and-effect
- site operating procedures
- statutory inspection requirements
- site water-treatment specification

Example timings, pressures and test sequences from training material are not presented as universal field setpoints.
